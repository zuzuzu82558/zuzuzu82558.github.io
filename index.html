What We Do

  • AI agent development — task-oriented agents with tool use, memory, guardrails and human-in-the-loop controls.
  • RAG document Q&A — retrieval-augmented question answering over complex documents, with citations and traceable evidence.
  • Multi-agent simulation — sandboxed multi-role agent environments for scenario rehearsal and decision support.
  • Workflow automation — LLM-powered automation for research, documentation and content operations.

Selected Work

HeteroSbox (NiJie) — Multi-Agent Simulation Sandbox

An open-source multi-agent simulation platform built with FastAPI. Multiple AI roles interact in a rule-governed sandbox with permission isolation, static reachability analysis of scenarios, and full audit trails. Source code: github.com/zuzuzu82558/heterosbox

Knowledge Agent — Document Q&A with Evidence

An enterprise document analysis agent combining hybrid retrieval (dense + sparse), knowledge graphs and LangGraph orchestration, designed so every answer can be traced back to its source evidence.
